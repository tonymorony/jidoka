# Changelog

A rule changes only from an incident or from the owner's word. Each change gets one entry here, the newest first:

- the date;
- the id of each rule that changes;
- what changes: a new rule, new words, a new strength, or a removal;
- the reason: the incident in one sentence, or the owner's words.

A rule keeps its id for as long as it exists. The id of a removed rule stays in this file, and no later rule takes it.
