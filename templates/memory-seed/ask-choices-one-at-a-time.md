A choice that blocks the work goes to the owner as one interactive question for each call, with the recommended option first. Choices that can wait go as one short numbered list, each item with its options, a recommendation and what happens with no answer. The owner answers by number: "1 ok, 2 ok".

**Why:** Decisions at the end of a long message pile up, and a numbered answer then no longer matches its list. One question with a recommendation takes the owner one word.

**How to apply:** Use the template `decision-list.md`. Start each item with what is true today, as verified. When the owner said not to interrupt, ask nothing: build the recommended option where the rules allow it, and put the choice on the list. When an "ok" can cover two things, take the narrow reading and say how you read it before you act. Write each answer on its ticket and in the state file. Never ask the owner for a fact that you can check yourself.
